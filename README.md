# E-Commerce Data Analysis

## 📌 Project Overview

This project analyzes e-commerce data to understand sales performance, customer behavior, product performance, and overall business trends.

The project uses **Python, SQL (MySQL), and Power BI** for data cleaning, analysis, visualization, and business insights.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook
* MySQL
* SQL
* Power BI
* Excel

## 🔄 Project Workflow

**Raw Data → Data Cleaning → Exploratory Data Analysis → SQL Analysis → Power BI Dashboard → Business Insights**

## 📊 Analysis Performed

### Python & Jupyter Notebook

* Data cleaning and preprocessing
* Missing value analysis
* Duplicate checking
* Data type handling
* Exploratory Data Analysis
* Sales and order analysis
* Product and customer analysis
* Data visualization

### SQL Analysis

SQL queries were performed using **MySQL through Command Prompt** to analyze the e-commerce data.

The analysis includes:

* Total sales
* Total orders
* Category-wise sales
* Product performance
* Customer analysis
* Sales trends
* Business performance metrics

### Power BI Dashboard

An interactive Power BI dashboard was created to visualize important business KPIs and trends.

Key metrics include:

* Total Sales
* Total Orders
* Total Quantity
* Average Order Value
* Category-wise Sales
* Region-wise Sales
* Sales Trends
